Building this as a package instead of three separate scripts really paid off. Once extract.py, transform.py, and display.py each had one job, adding the Operations report was easy — I only had to write one new function (summarize_by_day), because everything else already existed.

The biggest lesson was "coerce and carry on." Bad data like "N/A" or "one" used to crash my code until I wrapped the conversions in try/except and returned 0.0 or 0 instead. That way one bad row doesn't kill the whole report.

I also learned to tell import errors apart from logic errors. When __init__.py imports something that doesn't exist yet, every test disappears instead of just failing — that confused me for a while until I read the actual traceback instead of guessing.

Next time I want to get better at reading full error messages carefully before trying a fix, and committing/pushing more often so I don't lose points over something like a missing file.
